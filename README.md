# Barangay 143 Resident & Incident Management System

A JavaFX-based desktop application developed for managing barangay residents, incident reports, and inventory records.

## Features

### Resident Management
- Add residents
- Edit resident information
- Delete residents
- Search residents
- Resident status tracking

### Incident Reporting
- Create incident reports
- Edit incident reports
- Delete incident reports
- Incident status monitoring

### Dashboard
- Total residents
- Open incidents
- Resolved incidents
- Recent records overview

### Inventory Management
- Add inventory items
- Track stock levels
- Monitor inventory status

## Technologies Used

- Java
- JavaFX
- MySQL
- JDBC
- CSS
- NetBeans
